## Что настроено в коде

- Девять страниц с полноценным HTML, доступным без JavaScript: главная, четыре направления услуг, стоимость, контакты, полезное и уход за стяжкой.
- Уникальные title, description и H1, канонические HTTPS-адреса, внутренняя навигация и хлебные крошки.
- `robots.txt` с доступом для роботов, ссылкой на sitemap и Clean-param для рекламных параметров в Яндексе. Стили, JavaScript и изображения не закрыты.
- `sitemap.xml` содержит только основные адреса индексируемых страниц. В него не включены 404, файлы разработки и URL с рекламными параметрами. Фиктивные даты обновления не добавляются.
- JSON-LD: Organization с реальными предоставленными реквизитами, WebSite, WebPage, Service, BreadcrumbList и FAQPage с ответами, совпадающими с видимыми. Физический адрес не известен: разметка LocalBusiness и обещания расширенных результатов не добавлены. FAQ-разметка не гарантирует видимый FAQ в Google.
- Open Graph, Twitter Card, иконки и изображение для предпросмотра ссылок.
- Локальные шрифты, WebP, предварительная загрузка главного изображения и отложенная загрузка изображения процесса.
- Заметный телефон в шапке и закреплённый звонок на мобильных экранах.
- Цены за квадрат и денежный калькулятор удалены по указанию владельца. Условия стоимости зависят от объекта. Удалены показатели клиентов, стажа и срока гарантии, которые в исходной версии были взяты из другого бизнеса.

## GitHub Pages и домен

Проверьте настройки репозитория: https://github.com/yaroslavkiri4ykknifhit-max/crispy-fortnight/settings/pages

1. Источник публикации для этого статического репозитория: **Deploy from a branch → main → / (root)**. Если сайт уже размещён на другом хостинге, сохраняйте его размещение и подключайте домен там; приведённые ниже DNS нужны именно для GitHub Pages.
2. Укажите **krepkipol.by** в поле **Custom domain**. Файл `CNAME` с этим доменом уже включён в репозиторий. Он используется при публикации из ветки; при Actions-публикации домен задаётся в настройках Pages.

4. Дождитесь успешной проверки DNS и сертификата в Pages, затем включите **Enforce HTTPS**. Обновление DNS и выпуск сертификата могут занять время. Не оставляйте конфликтующие A/AAAA-записи парковки домена; почтовые MX/TXT не относятся к настройке сайта.
5. Проверьте, что http и www перенаправляются на https://krepkipol.by/ и что выбран основной домен без www. Перенаправления обеспечиваются хостингом, а не HTML.
6. Откройте главную, `/ceny/`, `/kontakty/`, `/robots.txt` и `/sitemap.xml`: ожидается HTTP 200. Для случайного несуществующего адреса ожидается HTTP 404 с собственной страницей ошибки.

## Google и Яндекс

После подключения домена:

1. Добавьте доменную собственность **krepkipol.by** в [Google Search Console](https://search.google.com/search-console). Подтвердите владение TXT-записью, которую выдаст сервис. Фиктивные verification-токены в сайт не добавлялись.
2. В разделе Sitemaps отправьте **https://krepkipol.by/sitemap.xml**. Проверьте главную и страницы услуг через «Проверку URL» и отправьте основные страницы на индексирование.
3. Добавьте **https://krepkipol.by** в [Яндекс Вебмастер](https://webmaster.yandex.ru/), подтвердите владение выданным токеном. Отправьте ту же sitemap, проверьте robots.txt, диагностику сайта и переобход основных страниц. Укажите реальный регион обслуживания — Гомель и Гомельскую область.
4. При наличии прежнего рабочего домена используйте постоянные перенаправления URL на соответствующие новые страницы и инструменты переезда в кабинетах поиска. Чужой easypol.by исходным доменом этого бизнеса не считается.
5. Заполните реальные карточки бизнеса в Google и Яндексе, соблюдая правила для выездных услуг. Для расширения данных нужны фактический адрес/формат обслуживания, фотографии реальных работ и настоящие отзывы. Не публикуйте вымышленный офис, часы работы или рейтинг.
6. При подключении аналитики используйте реальные идентификаторы Google Analytics / Яндекс Метрики; код без работающих ID не добавлялся. Для оценки рекламы отслеживайте клики по `tel:+375445776348` и реальные обращения. Клик по телефону ещё не подтверждает состоявшийся звонок или заказ.

## Дальнейшее продвижение

Техническая настройка помогает поисковикам читать сайт, но не гарантирует индексацию, позиции и постоянный поток заявок. Добавляйте собственные фотографии объектов, описание работ и подтверждённые отзывы; отслеживайте ошибки и поисковые запросы в кабинетах. Не создавайте десятки одинаковых страниц с заменой названия города.

Без доступа к регистратору, Search Console и Вебмастеру подключение домена и подтверждение собственности не выполнялись.

## Проверка перед публикацией

```sh
python tools/check_site.py
node --check script.js
```

Проверка запускается в GitHub Actions при изменениях страниц, стилей, скрипта и технических файлов. Она проверяет внутренние ссылки, метаданные, канонические адреса, sitemap, реквизиты и JSON-LD. Она не подтверждает реальную индексацию и DNS.
