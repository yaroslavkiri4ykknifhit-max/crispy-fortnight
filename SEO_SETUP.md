# Крепкий пол: подключение домена и поиска

Основной адрес в коде: **https://krepkipol.by/**. Сайт подготовлен для размещения в корне домена на внешнем хостинге. Внутренние ссылки идут от `/`; в репозитории нет `CNAME`. Название: **Крепкий пол**. Исполнитель: **ИП Кашурнин В.А.**, УНП **491689815**, телефон **+375445776348**. Настройки DNS, SSL и кабинета хостинга владелец выполняет отдельно.

## Что настроено в коде

- Девять страниц с полноценным HTML, доступным без JavaScript: главная, четыре направления услуг, стоимость, контакты, полезное и уход за стяжкой.
- Уникальные title, description и H1, канонические HTTPS-адреса `krepkipol.by`, внутренняя навигация и хлебные крошки.
- `robots.txt` размещается в корне домена и указывает на `https://krepkipol.by/sitemap.xml`. Стили, JavaScript и изображения не закрыты.
- `sitemap.xml` содержит только основные адреса индексируемых страниц. В него не включены 404, файлы разработки и URL с рекламными параметрами. Фиктивные даты обновления не добавляются.
- JSON-LD: Organization с реальными предоставленными реквизитами, WebSite, WebPage, Service, BreadcrumbList и FAQPage с ответами, совпадающими с видимыми. Физический адрес не известен: разметка LocalBusiness и обещания расширенных результатов не добавлены. FAQ-разметка не гарантирует видимый FAQ в Google.
- Open Graph, Twitter Card, иконки и изображение для предпросмотра ссылок.
- Локальные шрифты, WebP, предварительная загрузка главного изображения и отложенная загрузка изображения процесса.
- Заметный телефон в шапке и закреплённый звонок на мобильных экранах.
- Цены за квадрат и денежный калькулятор удалены по указанию владельца. Условия стоимости зависят от объекта. Удалены показатели клиентов, стажа и срока гарантии, которые в исходной версии были взяты из другого бизнеса.

## Размещение на внешнем хостинге

1. Добавьте **krepkipol.by** в панели хостинга как сайт, укажите его корневой каталог. DNS должны указывать на этот хостинг: используйте NS или A/AAAA, которые предоставляет выбранный провайдер. Адреса GitHub Pages для этого размещения не нужны. Не меняйте почтовые MX/TXT без необходимости.
2. Загрузите содержимое актуальной ветки `main` в корень сайта. `index.html`, `assets`, каталоги услуг, CSS, `script.js`, `robots.txt`, `sitemap.xml` и `site.webmanifest` должны находиться непосредственно в корне сайта, без папки `crispy-fortnight-main` или `crispy-fortnight` вокруг них. Сборка, Node.js и PHP не требуются.
3. Активируйте SSL-сертификат для **krepkipol.by** и, если используете это зеркало, **www.krepkipol.by**. После выпуска сертификата включите постоянное перенаправление с HTTP на HTTPS и с www на **https://krepkipol.by/** в панели хостинга. Перенаправления должны сохранять путь и рекламные параметры. HTML-перенаправление вместо серверного не добавлено.
4. На Apache файл `.htaccess` задаёт `DirectoryIndex index.html` и собственную страницу ошибки `ErrorDocument 404 /404.html`. Загрузите этот файл тоже. На хостинге с Nginx эти настройки задаются в панели или конфигурации сервера. Не включайте перенаправление всех неизвестных адресов на главную: несуществующие страницы должны возвращать HTTP 404.
5. Проверьте `https://krepkipol.by/`, `/ceny/`, `/kontakty/`, `/robots.txt`, `/sitemap.xml` и вложенную страницу `/polezno/uhod-za-styazhkoy/`: ожидается HTTP 200. Проверьте стили, изображения, меню и телефон на мобильном. Для случайного несуществующего адреса ожидается HTTP 404.
6. Обновите адрес в существующих кабинетах GA4 и Метрики, сохранив счётчики (инструкции ниже). Проверьте получение посещений и `phone_click` с нового домена.

В коде canonical, Open Graph, JSON-LD, sitemap, robots и manifest уже используют новый домен и пути от корня. DNS и SSL в этой задаче не настраивались. GitHub Pages не является целевым хостингом; файл `CNAME` для него не добавляется. Предпросмотр по прежнему проектному URL GitHub Pages после смены путей больше не предназначен для проверки сайта.

## Google и Яндекс

После подключения домена:

1. Добавьте доменную собственность **krepkipol.by** в [Google Search Console](https://search.google.com/search-console). Подтвердите владение TXT-записью, которую выдаст сервис. Фиктивные verification-токены в сайт не добавлялись.
2. В разделе Sitemaps отправьте **https://krepkipol.by/sitemap.xml**. Проверьте главную и страницы услуг через «Проверку URL» и отправьте основные страницы на индексирование.
3. Добавьте **https://krepkipol.by** в [Яндекс Вебмастер](https://webmaster.yandex.ru/), подтвердите владение выданным токеном. Отправьте ту же sitemap, проверьте robots.txt, диагностику сайта и переобход основных страниц. Укажите реальный регион обслуживания — Гомель и Гомельскую область.
4. При наличии прежнего рабочего домена используйте постоянные перенаправления URL на соответствующие новые страницы и инструменты переезда в кабинетах поиска. Чужой easypol.by исходным доменом этого бизнеса не считается.
5. Заполните реальные карточки бизнеса в Google и Яндексе, соблюдая правила для выездных услуг. Для расширения данных нужны фактический адрес/формат обслуживания, фотографии реальных работ и настоящие отзывы. Не публикуйте вымышленный офис, часы работы или рейтинг.
6. Google Analytics 4 подключён с предоставленным владельцем идентификатором `G-V1LNWC9XXD`. Яндекс Метрика подключена с предоставленным владельцем номером `113597384`.

## Google Analytics 4

- Google tag `G-V1LNWC9XXD` установлен один раз в `<head>` каждой HTML-страницы, включая 404. Просмотры страниц отправляет стандартная команда `gtag('config', ...)`.
- Общий `script.js` отправляет событие `phone_click` при нажатии любой ссылки `tel:`. Параметры: `contact_method: phone` и `link_location: header | mobile | footer | content`. Обработчик не задерживает и не отменяет открытие приложения для звонка. Номер посетителя, имя и другие данные из форм не передаются.
- `phone_click` означает нажатие на номер, а не состоявшийся звонок или заказ. Событие `generate_lead` для такого нажатия не отправляется.
- Проверка получения данных: откройте сайт без блокировщика аналитики, затем в GA4 откройте отчёт «В реальном времени». Проверьте посещение страницы и событие `phone_click` после нажатия номера. Если нужно учитывать это как ключевое событие, отметьте `phone_click` в настройках событий GA4.
- После размещения на `krepkipol.by` сохраняйте этот ресурс, поток и ID. В разделе «Администратор → Потоки данных» откройте веб-поток, измените URL сайта на `https://krepkipol.by/` и сохраните. Счётчик остаётся тем же, история сохраняется. Новый ресурс или поток создавать не нужно.
- Получение данных GA4 подтверждено скриншотами владельца: в отчёте «В реальном времени» появились посещения, просмотры страниц и событие `phone_click`.

## Яндекс Метрика

- Предоставленный код счётчика `113597384` установлен один раз в начале `<body>` каждой из десяти HTML-страниц, включая 404. Резервный пиксель находится в `noscript` внутри `body`.
- Сохранены настройки владельца: Вебвизор, карта кликов, отслеживание ссылок, точный показатель отказов и `ecommerce: "dataLayer"`. Сайт не отправляет события покупок: это сайт услуг без интернет-магазина.
- При нажатии любой ссылки `tel:` общий `script.js` вызывает `ym(113597384, 'reachGoal', 'phone_click', params)`. Параметры: `contact_method: phone`, `link_location: header | mobile | footer | content`. Вызовы GA4 и Метрики проверяются независимо: отсутствие одного счётчика не отключает отправку другому. Переход к звонку не задерживается.
- Для отчётов о конверсиях владелец должен добавить цель в кабинете счётчика: **Цели → Добавить цель → Целевое событие (JavaScript-событие)**. Название: **Нажатие на телефон**; идентификатор: **`phone_click`**, точно с таким регистром и подчёркиванием. Код события уже установлен; создание самой цели в кабинете без доступа к нему не выполнялось.
- Это цель нажатия на номер, а не подтверждённого звонка или заказа. Не суммируйте её с автоматической целью клика по телефону как два разных обращения.
- Проверка: посетите текущий сайт без блокировщика, нажмите номер, проверьте визит и достижение цели в Метрике. Получение данных Метрикой ещё должен подтвердить владелец; проверка кода не заменяет проверку отчётов.
- После размещения на `krepkipol.by` сохраните этот счётчик и обновите адрес сайта в его настройках на `https://krepkipol.by/`. Настройку адреса и создание цели выполняет владелец в кабинете Метрики.

Источники: [установка счётчика](https://yandex.ru/support/metrica/ru/general/creating-counter), [reachGoal](https://yandex.ru/support/metrica/ru/objects/reachgoal), [целевое событие](https://yandex.ru/support/metrica/ru/general/goal-js-event).

## Дальнейшее продвижение

Техническая настройка помогает поисковикам читать сайт, но не гарантирует индексацию, позиции и постоянный поток заявок. Добавляйте собственные фотографии объектов, описание работ и подтверждённые отзывы; отслеживайте ошибки и поисковые запросы в кабинетах. Не создавайте десятки одинаковых страниц с заменой названия города.

Доступ к хостингу, DNS, Search Console и Вебмастеру не предоставлялся. Код подготовлен; размещение, выпуск SSL и подтверждение собственности выполняет владелец.

```sh
python tools/check_site.py

```
